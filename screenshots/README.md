Keterangan:

- `top` = tangkapan layar satu viewport, cocok untuk banner/preview.
- `full` = seluruh halaman dari atas sampai footer, cocok untuk dokumentasi alur dan presentasi.
- Rute masing-masing portal: `#company`, `#youth`, dan `#admin`.
- Halaman login/registrasi berupa panel di atas beranda portal, dibuka lewat tombol header atau rute `#login` dan `#daftar`, lalu mengarahkan pengguna ke portal sesuai peran yang dipilih.
